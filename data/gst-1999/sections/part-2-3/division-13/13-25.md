# 13-25  The value of taxable importations that are partly non-taxable importations

If an importation (the actual importation) is:

<a id="s13-25-a"></a>
**(a)** partly a *taxable importation; and

<a id="s13-25-b"></a>
**(b)** partly a *non-taxable importation; the value of the part of the actual importation that is a taxable importation is the proportion of the value of the actual importation (worked out as if it were solely a taxable importation) that the taxable importation represents.
