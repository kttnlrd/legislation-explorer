# Tax agent lodgment programs ¶32-080

Although taxpayers must normally lodge their income tax returns by a fixed date each year, special extension arrangements are made for clients of tax agents to enable agents to spread their work over a substantial part of the year. See further ¶24-070. The Tax agent lodgment program 2023–24 and the Tax agent lodgment program 2024–25 are available on the ATO website (ato.gov.au). These detail the concessional lodgment due dates that a tax agent receives as a registered agent in respect of returns for the 12 months ending 30 June 2023 and 30 June 2024. There is also a lodgment program for FBT returns (¶35-030).
