# Where to lodge returns ¶24-080

The Commissioner normally directs the lodgment of a return to a particular address. If no such direction is given, the taxpayer may lodge the return at any office of a Deputy Commissioner. For individuals, the tax return instructions contain a pre-addressed envelope. As regards the electronic lodgment of returns, see ¶24-010.
