# 1101AA Variations to approved codes of conduct

**(1)** If an application is made to vary an approved code of conduct, ASIC may, by legislative instrument, approve the variation.

**(2)** Subsections 1101A(2) and (3) apply in relation to an application under subsection (1) as if it were an application to approve a code of conduct.
