# 29CC  Period for deciding applications


<a id="s29CC-1"></a>
**(1)** APRA must decide an application for an RSE licence within 90 days after receiving it, unless APRA extends the period for deciding the application under subsection (2).

<a id="s29CC-2"></a>
**(2)** APRA may extend the period for deciding the application by up to 30 days if APRA informs the body corporate, or a member of the group, that made the application of the extension:

> <a id="s29CC-2-a"></a>
> **(a)** in writing; and

> <a id="s29CC-2-b"></a>
> **(b)** within 90 days after receiving the application.

<a id="s29CC-3"></a>
**(3)** If APRA extends the period for deciding the application, it must decide the application within the extended period.

<a id="s29CC-4"></a>
**(4)** If APRA has not decided the application by the end of the period by which it is required to decide the application, APRA is taken to have decided, at the end of the last day of that period, to refuse the application.
