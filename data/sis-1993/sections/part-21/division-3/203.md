# 203  Application for civil penalty order precludes later criminal proceedings

proceedings Criminal proceedings for an offence constituted by a contravention of a civil penalty provision cannot be begun if a person has already applied for a civil penalty order in relation to the same contravention, even if the application has been finally determined or otherwise disposed of.
