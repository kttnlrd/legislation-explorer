# 701-67  Assets in this Part are CGT assets, etc.

This Part applies to an asset only if the asset is one or more of the following:

<a id="s701-67-a"></a>
**(a)** a *CGT asset;

<a id="s701-67-b"></a>
**(b)** a *revenue asset;

<a id="s701-67-c"></a>
**(c)** a *depreciating asset;

<a id="s701-67-d"></a>
**(d)** *trading stock;

<a id="s701-67-e"></a>
**(e)** a thing that is or is part of a *Division 230 financial arrangement. Exceptions
