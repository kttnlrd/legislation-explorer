# 709-210  Object of this Subdivision

The main object of this Subdivision is to ensure that the claimant can deduct the debt, or part of it, only if each entity that was owed the debt for a debt test period could have deducted the debt if it had been written off as bad at the end of the period. Limit on deduction of bad debt
