# 58-80 Meaning of undeducted pre-existing audited book value

<a id="s58-80-1"></a>
**(1)** The undeducted pre-existing audited book value of a *privatised asset is its *adjustable value in the hands of:

<a id="s58-80-1-a"></a>
**(a)** the *transition entity just before the *transition time; or

<a id="s58-80-1-b"></a>
**(b)** the *tax exempt vendor just before the *acquisition time; worked out using the assumptions in this section. Application of Division 40

<a id="s58-80-2"></a>
**(2)** Assume that Division 40 had always applied to work out the decline in value of the *privatised asset. Use for taxable purposes

<a id="s58-80-3"></a>
**(3)** Assume that, in applying Division 40 to the *privatised asset, it had always been used by the *transition entity or the *tax exempt vendor wholly for *taxable purposes. Cost

<a id="s58-80-4"></a>
**(4)** Assume that:

<a id="s58-80-4-a"></a>
**(a)** the first element of the *privatised asset's *cost to the *transition entity or the *tax exempt vendor is its *pre-existing audited book value as at the latest time (the test time) at which it had a pre-existing audited book value; and

<a id="s58-80-4-b"></a>
**(b)** no amount was included in the second element of the asset's cost before the test time; and Chapter 2 Non-assessable income Part 2-15 Capital allowances for depreciating assets previously owned by an exempt entity Division 58 Section 58-85

<a id="s58-80-4-c"></a>
**(c)** any amount included in the second element of the asset's cost after the test time had been incurred by the transition entity or the tax exempt vendor. Acquisition time

<a id="s58-80-5"></a>
**(5)** Assume that the *transition entity or the *tax exempt vendor had acquired the *privatised asset at the test time. Effective life

<a id="s58-80-6"></a>
**(6)** Assume that:

<a id="s58-80-6-a"></a>
**(a)** the *transition entity or the *tax exempt vendor had chosen to use an *effective life determined by the Commissioner for the *privatised asset as in force at the *transition time or the *acquisition time; and

<a id="s58-80-6-b"></a>
**(b)** subsection 40-95(2) did not apply.

**Note:** Section 40-102 does not apply to a privatised asset for the purposes of this section.

<a id="s58-80-7"></a>
**(7)** Assume also that section 40-110 (about recalculating effective life) did not apply.
