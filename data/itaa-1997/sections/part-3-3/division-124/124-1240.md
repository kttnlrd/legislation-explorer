# 124-1240 Roll-over consequences—all original interests were pre-CGT

If you acquire the new interest in exchange for: 

<a id="s124-1240-a"></a>
**(a)** one original interest that you started to *hold before 20 September 1985; or

<a id="s124-1240-b"></a>
**(b)** 2 or more original interests, each of which you started to hold before 20 September 1985; you are taken to have started to hold the new interest (or all of the new interests) before that day.
