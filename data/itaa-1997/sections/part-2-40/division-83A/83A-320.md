# 83A-320  Interests in a trust


<a id="s83A-320-1"></a>
**(1)**  This section applies if, at a time:

> <a id="s83A-320-1-a"></a>
> **(a)**  you hold an interest in a trust whose assets include *shares; and

> <a id="s83A-320-1-b"></a>
> **(b)**  that interest corresponds to a particular number of the shares (even if the interest does not correspond to particular shares). payments
