# 725-370  Uplifts in adjustable values of up interests under certain table items

Use the following method statement to work out the uplift in *adjustable value of an *up interest under:

> <a id="s725-370-a"></a>
> **(a)** item 1 or 2 of the table in subsection 725-250(2); or

> <a id="s725-370-b"></a>
> **(b)** item 1 of the table in subsection 725-335(3). Method statement Step 1.   If the *market value of the *up interest increases because of the *direct value shift, group together all up interests of the kind referred to in the relevant item that:

> <a id="s725-370-a-2"></a>
> **(a)** immediately before the *increase time, had the same *adjustable value as the up interest; and

> <a id="s725-370-b-2"></a>
> **(b)** sustained the same increase in market value as the up interest because of the *direct value shift. If the *up interest is issued at a *discount, group together all *up interests of the kind referred to in the relevant item that:

> <a id="s725-370-c"></a>
> **(c)** immediately before the *increase time, had the same *adjustable value as the up interest; and

> <a id="s725-370-d"></a>
> **(d)** because of the direct value shift, are issued at the same discount as the up interest. Step 2.    The notional adjustable value of the value shifted from the *down interests referred to in the relevant item to all the *up interests referred to in that item has already been worked out under one or more applications of step 3 of the method statement in section 725-365.
