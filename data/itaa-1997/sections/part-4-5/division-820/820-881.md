# 820-881 Application

This Subdivision applies to:

<a id="s820-881-a"></a>
**(a)** an entity (the relevant entity) that is a *general class investor, an *outward investing entity (non-ADI), or an *outward investing entity (ADI), for a period (the relevant period) that is all or a part of an income year; and

<a id="s820-881-b"></a>
**(b)** each entity (controlled entity of the relevant entity) that is an *Australian controlled foreign entity of which:

<a id="s820-881-i"></a>
**(i)** the relevant entity is an *Australian controller; or

<a id="s820-881-ii"></a>
**(ii)** an *associate entity of the relevant entity is an Australian controller.
