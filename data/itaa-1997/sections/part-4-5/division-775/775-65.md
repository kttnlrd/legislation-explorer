# 775-65 Only one forex realisation event to be counted

<a id="s775-65-1"></a>
**(1)** The following table applies to an option to buy a particular *foreign currency if the exercise price is payable in another foreign currency: Option to buy foreign currency Item If you are... and both of these this is the result... events happen when the option is exercised... 1 the entity who is (a) forex realisation ignore forex realisation capable of exercising event 1; event 4. the option (b) forex realisation event 4 2 the entity who is (a) forex realisation ignore forex realisation capable of exercising event 2; event 4. the option (b) forex realisation event 4 3 the entity who granted (a) forex realisation ignore forex realisation the option event 3; event 3.
