# 355-30  Supporting R&D activities

<a id="s355-30-1"></a>
**(1)** Supporting R&D activities are activities directly related to *core R&D activities.

<a id="s355-30-2"></a>
**(2)** However, if an activity:

> <a id="s355-30-2-a"></a>
> **(a)** is an activity referred to in subsection 355-25(2); or

> <a id="s355-30-2-b"></a>
> **(b)** produces goods or services; or

> <a id="s355-30-2-c"></a>
> **(c)** is directly related to producing goods or services; the activity is a supporting R&D activity only if it is undertaken for the dominant purpose of supporting *core R&D activities. Gambling and tobacco related activities etc.

<a id="s355-30-3"></a>
**(3)** If an activity relates to a matter or thing referred to in any of subparagraphs 355-25(2)(i)(i) to (iii) (which deal with gambling etc.):

> <a id="s355-30-3-a"></a>
> **(a)** subsection (2) does not apply to the activity; and

> <a id="s355-30-3-b"></a>
> **(b)** despite subsection (1), the activity is a supporting R&D activity only if it is covered by subsection 355-25(3) (harm minimisation purpose).

<a id="s355-30-4"></a>
**(4)** If an activity relates to a thing referred to in any of subparagraphs 355-25(2)(j)(i) to (vii) (which deal with tobacco and vaping goods etc.):

> <a id="s355-30-4-a"></a>
> **(a)** subsection (2) does not apply to the activity; and

> <a id="s355-30-4-b"></a>
> **(b)** despite subsection (1), the activity is a supporting R&D activity only if it is covered by subsection 355-25(4) (harm minimisation purpose).
