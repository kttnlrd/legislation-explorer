# 419-15  Meaning of critical mineral

<a id="s419-15-1"></a>
**(1)** Each of the following is a critical mineral:

> <a id="s419-15-1-a"></a>
> **(a)** antimony;

> <a id="s419-15-1-b"></a>
> **(b)** arsenic;

> <a id="s419-15-1-c"></a>
> **(c)** beryllium;

(d) bismuth;

> <a id="s419-15-e"></a>
> **(e)** chromium;

> <a id="s419-15-f"></a>
> **(f)** cobalt;

> <a id="s419-15-g"></a>
> **(g)** fluorine;

> <a id="s419-15-h"></a>
> **(h)** gallium;

> <a id="s419-15-i"></a>
> **(i)** germanium;

> <a id="s419-15-j"></a>
> **(j)** graphite;

> <a id="s419-15-k"></a>
> **(k)** hafnium;

> <a id="s419-15-l"></a>
> **(l)** high purity alumina;

> <a id="s419-15-m"></a>
> **(m)** indium;

> <a id="s419-15-n"></a>
> **(n)** lithium;

> <a id="s419-15-o"></a>
> **(o)** magnesium;

> <a id="s419-15-p"></a>
> **(p)** manganese;

> <a id="s419-15-q"></a>
> **(q)** molybdenum;

> <a id="s419-15-r"></a>
> **(r)** nickel;

> <a id="s419-15-s"></a>
> **(s)** niobium;

> <a id="s419-15-t"></a>
> **(t)** each of the following platinum-group elements:

> 
> **(i)** iridium;

> <a id="s419-15-ii"></a>
> **(ii)** osmium;

> <a id="s419-15-iii"></a>
> **(iii)** palladium;

> <a id="s419-15-iv"></a>
> **(iv)** platinum;

> <a id="s419-15-v"></a>
> **(v)** rhodium;

> <a id="s419-15-vi"></a>
> **(vi)** ruthenium;

> <a id="s419-15-u"></a>
> **(u)** each of the following rare-earth elements:

> 
> **(i)** cerium;

> 
> **(ii)** dysprosium;

> 
> **(iii)** erbium;

> 
> **(iv)** europium;

> 
> **(v)** gadolinium;

> 
> **(vi)** holmium;

> <a id="s419-15-vii"></a>
> **(vii)** lanthanum;

> <a id="s419-15-viii"></a>
> **(viii)** lutetium;

> <a id="s419-15-ix"></a>
> **(ix)** neodymium;

(x) praseodymium;

> <a id="s419-15-xi"></a>
> **(xi)** promethium;

> <a id="s419-15-xii"></a>
> **(xii)** samarium;

> <a id="s419-15-xiii"></a>
> **(xiii)** terbium;

> <a id="s419-15-xiv"></a>
> **(xiv)** thulium;

> <a id="s419-15-xv"></a>
> **(xv)** ytterbium;

> <a id="s419-15-xvi"></a>
> **(xvi)** yttrium;

> 
> **(v)** rhenium;

> <a id="s419-15-w"></a>
> **(w)** scandium;

> <a id="s419-15-x"></a>
> **(x)** selenium;

> <a id="s419-15-y"></a>
> **(y)** silicon;

> <a id="s419-15-z"></a>
> **(z)** tantalum;

> <a id="s419-15-za"></a>
> **(za)** tellurium;

> <a id="s419-15-zb"></a>
> **(zb)** titanium;

> <a id="s419-15-zc"></a>
> **(zc)** tungsten;

> <a id="s419-15-zd"></a>
> **(zd)** vanadium;

> <a id="s419-15-ze"></a>
> **(ze)** zirconium;

> <a id="s419-15-zf"></a>
> **(zf)** a thing prescribed by the regulations.

<a id="s419-15-2"></a>
**(2)** The regulations must not prescribe uranium for the purposes of paragraph (1)(zf).
