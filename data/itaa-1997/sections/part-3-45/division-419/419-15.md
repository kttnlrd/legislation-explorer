# 419-15 Meaning of critical mineral

<a id="s419-15-1"></a>
**(1)** Each of the following is a critical mineral:

<a id="s419-15-1-a"></a>
**(a)** antimony;

<a id="s419-15-1-b"></a>
**(b)** arsenic;

<a id="s419-15-1-c"></a>
**(c)** beryllium;

<a id="s419-15-1-d"></a>
**(d)** bismuth;

<a id="s419-15-1-e"></a>
**(e)** chromium;

<a id="s419-15-1-f"></a>
**(f)** cobalt;

<a id="s419-15-1-g"></a>
**(g)** fluorine;

<a id="s419-15-1-h"></a>
**(h)** gallium;

<a id="s419-15-1-h-i"></a>
**(i)** germanium;

<a id="s419-15-1-j"></a>
**(j)** graphite;

<a id="s419-15-1-k"></a>
**(k)** hafnium;

<a id="s419-15-1-l"></a>
**(l)** high purity alumina;

<a id="s419-15-1-m"></a>
**(m)** indium;

<a id="s419-15-1-n"></a>
**(n)** lithium;

<a id="s419-15-1-o"></a>
**(o)** magnesium;

<a id="s419-15-1-p"></a>
**(p)** manganese;

<a id="s419-15-1-q"></a>
**(q)** molybdenum;

<a id="s419-15-1-r"></a>
**(r)** nickel;

<a id="s419-15-1-s"></a>
**(s)** niobium;

<a id="s419-15-1-t"></a>
**(t)** each of the following platinum-group elements:

<a id="s419-15-1-t-i"></a>
**(i)** iridium;

<a id="s419-15-1-t-ii"></a>
**(ii)** osmium;

<a id="s419-15-1-t-iii"></a>
**(iii)** palladium;

<a id="s419-15-1-t-iv"></a>
**(iv)** platinum;

<a id="s419-15-1-t-v"></a>
**(v)** rhodium;

<a id="s419-15-1-t-vi"></a>
**(vi)** ruthenium;

<a id="s419-15-1-u"></a>
**(u)** each of the following rare-earth elements:

<a id="s419-15-1-u-i"></a>
**(i)** cerium;

<a id="s419-15-1-u-ii"></a>
**(ii)** dysprosium;

<a id="s419-15-1-u-iii"></a>
**(iii)** erbium;

<a id="s419-15-1-u-iv"></a>
**(iv)** europium;

<a id="s419-15-1-u-v"></a>
**(v)** gadolinium;

<a id="s419-15-1-u-vi"></a>
**(vi)** holmium;

<a id="s419-15-1-u-vii"></a>
**(vii)** lanthanum;

<a id="s419-15-1-u-viii"></a>
**(viii)** lutetium;

<a id="s419-15-1-u-ix"></a>
**(ix)** neodymium;

<a id="s419-15-1-u-x"></a>
**(x)** praseodymium;

<a id="s419-15-1-u-xi"></a>
**(xi)** promethium;

<a id="s419-15-1-u-xii"></a>
**(xii)** samarium;

<a id="s419-15-1-u-xiii"></a>
**(xiii)** terbium;

<a id="s419-15-1-u-xiv"></a>
**(xiv)** thulium;

<a id="s419-15-1-u-xv"></a>
**(xv)** ytterbium;

<a id="s419-15-1-u-xvi"></a>
**(xvi)** yttrium;

<a id="s419-15-1-u-v-2"></a>
**(v)** rhenium;

<a id="s419-15-1-w"></a>
**(w)** scandium;

<a id="s419-15-1-w-x"></a>
**(x)** selenium;

<a id="s419-15-1-y"></a>
**(y)** silicon;

<a id="s419-15-1-z"></a>
**(z)** tantalum;

<a id="s419-15-1-za"></a>
**(za)** tellurium;

<a id="s419-15-1-zb"></a>
**(zb)** titanium;

<a id="s419-15-1-zc"></a>
**(zc)** tungsten;

<a id="s419-15-1-zd"></a>
**(zd)** vanadium;

<a id="s419-15-1-ze"></a>
**(ze)** zirconium;

<a id="s419-15-1-zf"></a>
**(zf)** a thing prescribed by the regulations.

<a id="s419-15-2"></a>
**(2)** The regulations must not prescribe uranium for the purposes of paragraph (1)(zf).
