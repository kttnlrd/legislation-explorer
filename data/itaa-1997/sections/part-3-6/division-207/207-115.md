# 207-115 Which exempt institutions are eligible for a refund?

<a id="s207-115-1"></a>
**(1)** This section sets out the only circumstances in which an entity is an exempt institution that is eligible for a refund. Income tax exempt charities

<a id="s207-115-2"></a>
**(2)** An entity is an exempt institution that is eligible for a refund if it:

> <a id="s207-115-2-a"></a>
> **(a)** is covered by item 1.1 of the table in section 50-5; and

> <a id="s207-115-2-b"></a>
> **(b)** is endorsed as exempt from income tax under Subdivision 50-B; and

> <a id="s207-115-2-c"></a>
> **(c)** satisfies the *residency requirement. Income tax exempt deductible gift recipients

<a id="s207-115-3"></a>
**(3)** An entity is an exempt institution that is eligible for a refund if it:

> <a id="s207-115-3-a"></a>
> **(a)** is endorsed under paragraph 30-120(a); and

> <a id="s207-115-3-b"></a>
> **(b)** satisfies the *residency requirement. Income tax exempt specified deductible gift recipients

<a id="s207-115-4"></a>
**(4)** An entity is an exempt institution that is eligible for a refund if:

> <a id="s207-115-4-a"></a>
> **(a)** the entity's name is specified in a table in a section in Subdivision 30-B; and

> <a id="s207-115-4-b"></a>
> **(b)** it has an ABN; and

> <a id="s207-115-4-c"></a>
> **(c)** it satisfies the *residency requirement. Income tax exempt subsidiaries of the Future Fund Board (5A) An entity is an exempt institution that is eligible for a refund if it is covered by item 5.4 of the table in section 50-25. Prescribed income tax exempt entities

<a id="s207-115-6"></a>
**(6)** An entity is an exempt institution that is eligible for a refund if the entity is prescribed as an exempt institution that is eligible for a refund by the regulations.

<a id="s207-115-7"></a>
**(7)** This section has effect subject to sections 207-119 to 207-136.
