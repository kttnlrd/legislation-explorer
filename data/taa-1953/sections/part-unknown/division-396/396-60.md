# 396-60  Information required

Transactions not involving market participants

<a id="s396-60-1"></a>
**(1)**  For the purposes of section 396-55, the information required by the *approved form about a transaction (other than a transaction described in table item 5 in that section):

> <a id="s396-60-1-a"></a>
> **(a)**  must relate to:

> > <a id="s396-60-1-a-i"></a>
> > **(i)**  the identification, collection or recovery of a possible *tax-related liability; or

> > <a id="s396-60-1-a-ii"></a>
> > **(ii)**  the identification of a possible reduction of a possible tax-related liability; of a party to the transaction (disregarding any exemption under a *taxation law that may apply to those parties); and

> <a id="s396-60-1-b"></a>
> **(b)**  may relate to identifying the parties to the transaction; and

> <a id="s396-60-1-c"></a>
> **(c)**  for a transaction described in table item 3 in that section— may include the *tax file numbers of those parties to the transaction who have quoted their tax file numbers to the State or Territory concerned. Transactions involving market participants

<a id="s396-60-2"></a>
**(2)**  For the purposes of section 396-55, the information required by the *approved form about a transaction described in table item 5 in that section must relate to identifying the parties to the transaction. Some reporting entities may request tax file numbers

<a id="s396-60-3"></a>
**(3)**  A State or Territory may request an entity to quote the entity's *tax file number to the State or Territory if:

> <a id="s396-60-3-a"></a>
> **(a)**  the tax file number is for a report by the State or Territory under section 396-55 about a transaction described in table item 3 in that section; and

> <a id="s396-60-3-b"></a>
> **(b)**  the entity is a party to the transaction. Authorised Version C2026C00170 registered 28/04/2026 Part 5-25 Record-keeping and other obligations relating to taxpayers Section 396-65
