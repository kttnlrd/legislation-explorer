# 202BF  Alteration of tax file numbers

The Commissioner may, at any time, by written notice given to a person who has a tax file number:

<a id="s202BF-a"></a>
**(a)** withdraw that number; and

<a id="s202BF-b"></a>
**(b)** issue to the person a new tax file number in place of the withdrawn number. Tax file numbers Part VA Quotation of tax file numbers by recipients of eligible PAYG payments Division 3 Section 202C
