# 266-165  There must be no abnormal trading (subject to 50% stake exception)


<a id="s266-165-1"></a>
**(1)** There must be no abnormal trading in the units of the trust during the test period. To find out the meaning of abnormal trading: see Subdivision 269-B. in ownership Section 266-170

<a id="s266-165-2"></a>
**(2)** If there is abnormal trading on one or more occasions, then for each abnormal trading the trust must pass the 50% stake test in respect of the following times:

<a id="s266-165-2-a"></a>
**(a)** the beginning of the test period;

<a id="s266-165-2-b"></a>
**(b)** immediately after the abnormal trading. To find out whether the trust passes the 50% stake test: see Subdivision 269-C.
