# Section Change Logs

Per-section change logs for the legislation corpus. One file per changed section, one
directory per act:

```
docs/changes/<act>/<section>.md
```

Each file records the date and a one-line summary of what changed and why. Append new dated
entries to the same file on future changes to that section (do not overwrite).

Kept outside `data/` so corpus frontmatter and API responses are unchanged.
