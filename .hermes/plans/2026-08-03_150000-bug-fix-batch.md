### Task A3: Fix `get_definition` boundary detection for other acts

**Objective:** `get_definition` only reliably resolves ITAA 1997 s 995-1 definitions. ITAA 1936 "dividend" (defined in s 6(1)) → not-found. GST "enterprise" (s 195-1) → not-found. The 500-char truncation cap also needs removal.

**Files:**
- Modify: `backend/services/data_loader.py` — `get_definition_text()` function (lines ~680-720+)

**Step 1: Analyze current boundary detection**
The current regex `re.search(r'\n(?=[^\s>#<\-\[\(\\'"'\\'])', rest)` is too broad — it fires on any vertical whitespace followed by a non-special char. Replace with more precise boundary detection:
```python
# Terminate at the next definition anchor or heading
m2 = re.search(r'(?:\n)(?=\w)', rest[1:])  # col-0 word start (skip first char)
m3 = re.search(r'\n####\s', rest)  # next definition heading
m4 = re.search(r'\n<a id="', rest)  # next anchor
```

**Step 2: Remove arbitrary 500-char cap**
Remove the lines that truncate at 500 chars. Add `truncated: bool` and `full_text_available: bool` fields.

**Step 3: Handle ITAA 1936 s 6 definition format**
ITAA 1936 uses `(1)` subsection markers inline rather than `####` headings. Add a mode that detects subsection-numbered definitions and extracts the right range.

**Step 4: Verify**
